# Nighty

Expo React Native app powered by TypeScript.

## Start the app

```bash
npm start
```

Then scan the QR code with Expo Go, or press `w` for web, `a` for Android, or `i` for iOS.

## Available scripts

- `npm start` - start the Expo development server
- `npm run android` - start the app on Android
- `npm run ios` - start the app on iOS (macOS required)
- `npm run web` - start the web build
